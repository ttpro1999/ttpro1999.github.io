Khám phá C_ultra: Học RTOS Kernel qua Monorepo Độc lập

Xin chào mọi người! Hôm nay tôi muốn chia sẻ về một dự án thú vị mà tôi đã làm việc trong thời gian gần đây: C_ultra - một kho lưu trữ học tập về các kernel RTOS đa dạng.

Dự án là gì?

C_ultra là một monorepo chứa nhiều kernel RTOS độc lập, được thiết kế để học các khái niệm lập trình hệ thống một cách có hệ thống. Không giống như nhiều dự án khác dùng chung một core, mỗi kernel trong C_ultra là một subproject hoàn toàn tự trị với CMake build riêng.

Tại sao thiết kế như vậy?

Nguyên tắc cốt lõi: Các kernel KHÔNG chia sẻ code. Mỗi kernel được xây dựng độc lập để minh họa rõ ràng các pattern scheduling/IPC khác nhau. Điều này giúp:

  • Hiểu sâu sắc từng khái niệm
  • So sánh dễ dàng giữa các approach
  • Tránh sự phức tạp không cần thiết

Cấu trúc dự án

kernels/
├── 00_minirtos_coop/          # Cooperative scheduling
├── 01_minirtos_preempt_rr/    # Preemptive round-robin
├── 02_fixed_priority/         # Fixed-priority (sắp tới)
├── 03_edf_scheduler/          # EDF scheduling (sắp tới)
└── 10-12_*/                   # Microkernel designs (sắp tới)

labs/                          # Bài tập data structures
├── linked_list/
├── ring_buffer/
└── ...

docs/                          # Tài liệu và roadmap

Các kernel hiện có

Kernel 00: Cooperative Scheduling

  • Tasks phải tự nguyện nhường CPU qua sched_yield()
  • Scheduler dùng circular ready queue
  • IPC qua message queues với copy-based
  • Sleep mechanism: linear scan sleeping tasks

Kernel 01: Preemptive Round-Robin

  • Tick thread gọi sched_on_tick() để rotate queue
  • Time slice = 1 tick (configurable trong tương lai)
  • Không cần scan sleep queue

Cách build và chạy

Mỗi kernel build độc lập:

# Build kernel 00
cmake -S kernels/00_minirtos_coop -B build/00 && cmake --build build/00 -j
./build/00/rtos_demo_00

# Build kernel 01
cmake -S kernels/01_minirtos_preempt_rr -B build/01 && cmake --build build/01 -j
./build/01/rtos_demo_01

Host Simulation

Tất cả chạy trên WSL/POSIX sử dụng:

  • pthread cho concurrency
  • nanosleep() cho tick generation
  • pthread_cond_timedwait() cho blocking IPC

Quan trọng: Đây là simulation giáo dục, không phải embedded HAL thật.

Labs: Data Structures Practice

Ngoài kernels, còn có labs/ với các bài tập độc lập:

  • Ring buffer
  • Linked list (circular doubly-linked)
  • Và nhiều hơn nữa

Design Philosophy

Task Control Block (TCB)

Tất cả kernels dùng task_t struct với circular doubly-linked list embedding:

typedef struct task {
  struct task* next;
  struct task* prev;
  const char*  name;
  void (*entry)(void*);
  task_state_t state;
  uint64_t     wakeup_tick;
  int          priority;
} task_t;

Header Organization

  • include/rtos/ chứa public APIs
  • src/ chứa implementation với suffix chỉ scheduler variant
  • apps/ chứa demo applications
  • sim/ chứa host simulation helpers

Roadmap tương lai

  • Kernel 02-03: Fixed-priority và EDF scheduling
  • Kernel 10-12: Microkernel designs (Zircon/seL4/QNX-inspired)

Tại sao dự án này thú vị?

  1. Progressive Learning: Từ cooperative → preemptive → advanced scheduling
  2. Clean Architecture: Mỗi kernel là standalone, dễ hiểu
  3. Educational Focus: Simulation trên host, không cần hardware
  4. Real RTOS Comparison: Tham khảo FreeRTOS, Zircon, seL4, QNX

Kết luận

C_ultra là một cách tuyệt vời để học RTOS từ cơ bản đến nâng cao. Thiết kế monorepo với các kernel độc lập giúp tập trung vào từng khái niệm mà không bị phân tâm bởi code chung.

Nếu bạn quan tâm đến systems programming, embedded development, hoặc chỉ muốn hiểu cách RTOS hoạt động, hãy thử clone repo và build một kernel xem sao!
