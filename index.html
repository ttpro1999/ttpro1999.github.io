What is C_ultra?

C_ultra is a monorepo of independent kernel implementations, demonstrating progressively complex RTOS concepts from cooperative scheduling to microkernel architectures.

This blog documents the engineering journey — not just "how to implement" data structures, but why we design systems the way we do in kernel-level programming.

Architecture

C_ultra consists of:

  • kernels/ — Multiple RTOS implementations (00_minirtos_coop, 01_minirtos_preempt_rr, ...)
  • labs/ — Standalone data structure exercises with progressive complexity
  • docs/ — Design rationale and architecture comparisons

Key Philosophy

"Each kernel is self-contained to illustrate specific scheduling/IPC patterns clearly. We don't share code between kernels — we learn by building independently."

About This Blog

These are engineering essays, not tutorials. Each post:

  • Starts with a real problem (ISR latency, task scheduling constraints)
  • Shows naive solutions and their failures
  • Introduces elegant designs grounded in invariants
  • Connects back to real RTOS (FreeRTOS, Linux, QNX, seL4)

For more information, visit the GitHub repository.
